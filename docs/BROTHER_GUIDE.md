# HOW TO JOIN THE GAME (for the person joining)

You do **not** need Unreal Engine. Just these steps.

## One-time setup

### 1. Install Radmin VPN
1. Go to **radmin-vpn.com** → **Download** → install it → open it.
2. Click **Network → Join Network**.
3. Type the **network name** and **password** your brother sent you → **Join**.
4. You should see his computer in the list with a **green dot**.

### 2. Get the game
1. Download the **zip** your brother sent you.
2. Right-click it → **Extract All** → **Extract**.
3. Open the extracted folder → open **Windows** → you'll see **`PiratesVsVikings.exe`**.
   (Tip: right-click it → **Send to → Desktop (create shortcut)**.)
4. ⚠️ Don't open any file that ends in **.uproject** — that's not the game.

### 3. First launch
1. Double-click **`PiratesVsVikings.exe`**.
2. If Windows says **"Windows protected your PC"** → **More info** → **Run anyway**.
3. If Windows asks about the **firewall** → click **Allow** (tick both Private and Public).

## Every time you play

1. Open **Radmin VPN** (make sure your brother has the green dot).
2. Wait until your brother says **"I'm hosting"**.
3. Open **`PiratesVsVikings.exe`** → the menu appears.
4. Pick your side: **RUNNER** or **BORDER PATROL**.
5. In the box that says *Host's IP*, type your brother's **Radmin IP** (it starts with **26.**, e.g. `26.12.34.56`).
6. Click **JOIN IP**. You'll load into his game.

### Or with a Steam invite
1. Have **Steam** open and logged in.
2. When your brother invites you, a Steam message pops up → **Accept**. (Steam calls it "Spacewar" — that's normal.)
3. The game opens/joins his match.

## Controls
| Key | What it does |
|---|---|
| WASD / Mouse | Move / look |
| Shift | Sprint · **C** = crouch · **Space** = jump (or struggle when zip-tied) |
| Left click | Punch (or shoot while aiming) |
| Hold right click | Aim · **R** = reload |
| E | Interact (tap or hold) — shops, jobs, trucks, zip-ties, rescue |
| F | Eat a taco |
| M | Menu (switch team) |
| In a truck | W/S/A/D drive · **R/T** radio · **H** horn · **E** get out |
| Border Patrol only | **X** taser/gun · **V** scanner · **B** trap · **Q** drone |

## Problems?
- **Can't connect:** check Radmin shows your brother **online** (green), and the IP is typed right.
- **"Version mismatch" or kicked right away:** ask your brother for the newest zip.
- **Firewall:** Windows Security → Firewall & network protection → **Allow an app through firewall** → tick **PiratesVsVikings** (Private + Public).
